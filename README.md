# Kas UMKM

Kas UMKM adalah aplikasi pembukuan sederhana untuk membantu mencatat transaksi dan memantau keuangan usaha. Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript, serta Firebase untuk autentikasi dan penyimpanan data.

## Struktur Proyek

```text
kas_umkm
├── app.js       # Logika aplikasi dan integrasi Firebase
├── index.html   # Halaman utama aplikasi
├── README.md    # Dokumentasi proyek
└── style.css    # Tampilan dan tata letak
```

## Menjalankan Aplikasi

Buka `index.html` melalui server lokal atau hosting web. Aplikasi memerlukan koneksi internet untuk memuat Firebase.
